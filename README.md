# 🐾 Animal Sanctuary Native Client

A React Native (Expo) mobile client built to supplement my MERN stack Animal API.

## Prerequisites
* Node.js installed
* Backend MERN server running locally on port `5000` (with MongoDB active)
* Expo Go app (for physical devices) or Xcode / Android Studio Simulator

## Setup & Installation
1. Clone the `production` branch:
   ```bash
   git clone -b production <your-github-repo-url>
   cd animal-native-client
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Expo development server:
   ```bash
   npx expo start
   ```
4. Press `i` to open in the iOS Simulator, `a` for Android Emulator, or scan the QR code using Expo Go.
